# b1api Browser Controls

Separate browser-extension companion for b1api.

It does not implement network filtering, cosmetic filtering, filter-list subscriptions, or blocked-request statistics.

It provides browser-level per-site controls for JavaScript, popups, cookies, notifications, camera, microphone, location, images, and sound, plus a popup and dashboard.

## Install in Brave / Chromium
1. Open the browser extensions page.
2. Enable Developer mode.
3. Choose Load unpacked.
4. Select this `b1api-browser` folder.
5. Pin the extension.

A normal website cannot grant itself these browser-level privileges; the companion must be installed as an extension.
